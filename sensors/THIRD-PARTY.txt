MiniPulse does not disable driver signing, security protections, or install an unrestricted driver.
PawnIO is shared system software and is NOT removed when MiniPulse is uninstalled.

Sensors.cs is MiniPulse MIT source. The helper only reads sensor values and exits
when the UI closes; there is no persistent elevated service or hardware control API.
