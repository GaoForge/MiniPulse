MiniPulse 1.6.4

双击程序即自动请求管理员权限，无需右键选择“以管理员身份运行”；Windows 仍会显示 UAC 授权提示。
已移除 AI 应用监测、进程归属采样与相关弹窗，仅保留 CPU、内存、磁盘和网络。
支持 Windows 11 x64。为当前 Windows 管理员账户开启登录自启后，任务计划程序会在该账户登录时启动 MiniPulse，无需再次确认 UAC。

安装程序默认供所有用户使用，需要管理员权限。
下一步可以选择安装目录。首次安装时可选桌面快捷方式和登录自启；原目录升级会保留已有的自启状态。
可在托盘菜单开启或关闭登录自启。启用前请将程序放在受管理员保护的本地目录，例如默认安装目录。移动便携版或更换安装目录前，请先从原位置关闭自启。

启动后，MiniPulse 显示在任务栏右侧的系统托盘中。
若未看到图标，请展开托盘隐藏图标区域。
任务栏指标栏默认显示在托盘左侧的可用空白区域，分为 CPU、内存、磁盘和网络四组。
常驻显示占用率、可用温度、磁盘读取/写入和网络下载/上传速度。
RAM 第二行显示可用容量，悬停可看已用/总容量、系统缓存、提交内存及可用温度。
CPU 第二行在采集可用时同时显示当前最高核心频率和温度。
CPU 悬停详情显示核心均频、当前最高核心、本次实测频率峰值，以及支持时的基准频率/硬件报告上限。
频率为约每秒采集的核心时钟，不是有效频率；本次峰值可能漏掉短暂睿频，不能当作处理器理论上限。
基准和硬件上限从支持的 Intel CPUID 读取；基准也可读取 CPU 品牌字符串明确给出的标称频率。
未知上限不会猜测，未知基准时不会判断睿频区间；实时频率需启用管理员采温组件。
磁盘常驻数字为所有硬盘合计，悬停可看各块物理硬盘和盘符的分项读写速度。
同一行多个盘符代表同一块物理硬盘的不同分区，不是各分区独立速度。
指标栏采用半透明底色和更大加粗文字，四组内容居中、分隔线两侧留白一致；详情卡片使用暗黑风格。
指标栏保留 CPU、内存、磁盘和网络四组。紧凑版默认宽度 360、高度 36（按屏幕缩放调整），悬停 CPU/内存可查看温度数据源状态。
鼠标停留约 250 毫秒后弹出对应详情，包含实时指标、最近最多 45 次采样趋势以及补充信息。
鼠标可以移入详情卡片继续查看，移出指标栏和卡片后自动收起；查看不会抢占键盘焦点。
程序会自动按缩放比例调整大小并避开可识别的任务栏按钮。
空间不足或无法识别布局时不强行覆盖按钮，可从右键菜单切换到任务栏上方。
悬停指标栏查看对应分项详情；点击指标栏或详情不打开总览。总览窗口已移除。
左键或右键单击托盘图标：打开设置菜单。
右键单击图标：打开菜单，选择“退出 MiniPulse”结束程序。

升级或卸载前，请先从托盘右键菜单退出 MiniPulse。
卸载入口：Windows 设置 → 应用 → 安装的应用 → MiniPulse。

独立采温使用 LibreHardwareMonitor 0.9.6 + PawnIO 2.2.0，依赖 Windows .NET Framework 4.7.2 或更新版本。
安装时默认勾选硬件采温，完成页会启动原始 PawnIO 安装向导，请使用官方签名版本。
双击 MiniPulse 时自动请求管理员权限，确认 Windows UAC 弹窗后启动并自动采温。
采温组件继承主程序权限；无需右键管理员启动或再次单独授权。右键菜单可重试硬件采温。
取消启动时的 UAC 授权会取消启动。已有监控软件公开的 WMI 数据仍可作为备用来源。
静默安装不会安装 PawnIO 或启动提权采温。内存温度依赖硬件支持；没有传感器时显示“—”。
CPU 优先显示封装温度，否则显示最热核心；内存只使用明确标注的内存温度传感器。
本程序不用主板或 ACPI 温度代替 CPU/内存温度，采温进程随主程序退出。
PawnIO 为共享驱动，卸载 MiniPulse 时会保留；如不再需要，可从 Windows 设置单独卸载。
磁盘读写速度为全部物理磁盘的合计，指标栏 K/s 和 M/s 分别表示 KiB/s 和 MiB/s。
本版本不包含 GPU 监控。第三方组件许可证与源码链接在 sensors 文件夹中。
